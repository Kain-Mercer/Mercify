# Helping out

Thanks for trying Mercify! The most useful things you can do:

## Report a bug

[Open an issue](https://github.com/Kain-Mercer/Mercify/issues) and include:

- **What happened**, and what you expected instead.
- **Your Mercify version** (top of the *Updates* section in Settings).
- **A screenshot**, if you can.
- If the overlay hid or your game lost the keyboard: right-click the tray icon, choose **Copy diagnostics** straight afterwards, and paste it in.

## Suggest an idea

Open an issue describing what you'd like Mercify to do and why. Small, specific ideas are the easiest to pick up.

## Work on the code

Mercify is an Electron app plus a small Spicetify extension. The [developer guide](docs/DEVELOPING.md) explains how it fits together, how to run it from source, the test tools, and how releases are built.

Keep changes focused, test on Windows where you can, and describe what you checked in your pull request.
